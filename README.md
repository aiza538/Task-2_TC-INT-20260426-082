## Objective

Improve and redesign the existing TEYZIX CORE website with better UI/UX, responsiveness, and modern design elements while keeping original branding.

## Features Implemented

- Modern homepage design with gradient backgrounds
- Sticky navbar with mobile hamburger menu
- Complete footer with social links
- Dark/Light theme toggle with localStorage persistence
- Smooth scroll and animated hover effects
- Portfolio section showcasing projects
- Contact form with success message
- Back to top button

## Tech Stack

- React 18 with Vite
- Tailwind CSS
- Lucide React Icons

I## nstallation and Running Instructions

Step 1: Install Node.js
Download and install Node.js from nodejs.org (version 16 or higher)

Step 2: Extract ZIP File
Extract Task-2_TC-INT-20260426-082.zip to your computer

Step 3: Open Terminal
Navigate to the project folder using command prompt or terminal

Step 4: Install Dependencies
Run this command: npm install

Step 5: Install Additional Packages
Run this command: npm install lucide-react

Step 6: Install Tailwind CSS
Run these commands:
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

Step 7: Start Development Server
Run this command: npm run dev

Step 8: Build for Production
Run this command: npm run build
